# Reproduce the tutorial figures

The correlation scatterplot is generated by the executed GWAS-to-moments R workflow in [Fifteen-trait correlations](../Fifteen-trait-correlations.md). It compares the 105 freshly estimated GCMSEM correlations against unmodified standard LDSC. After creating `comparison` in that tutorial, draw or save it:

```r
plot(comparison)
png("correlation-scatterplot.png", width = 1600, height = 1500, res = 220)
plot(comparison)
dev.off()
pdf("correlation-scatterplot.pdf", width = 1600 / 220, height = 1500 / 220)
plot(comparison)
dev.off()
```

The six `hw-*.png` and `bs-*.png` figures show the forward, reverse and reciprocal model specifications. Each has a PDF counterpart. They are drawn from `gcmsem_model` objects using the dependency-free R helper in [plot_models.R](../plot_models.R):

```r
source("tutorials/plot_models.R")
plot_causal_model(hw_model, "Height to weight with a common source")
```

The [causal tutorial](../Causal-examples.md) defines each model beside its diagram. Rectangle nodes are traits, elliptical nodes are sources, and arrows carry parameter names or fixed values. The diagrams show assumptions, not fitted effect estimates. The numerical datasets remain in the external release.

The three `polygenicity-*.png` figures and PDF counterparts come from the executed [15-trait S-LD4M comparison](../Polygenicity.md). After running that tutorial:

```r
plot(result, uncertainty = FALSE)
plot(result, uncertainty = TRUE)
plot(result, uncertainty = FALSE, input = "beta")
```

The first uses original S-LD4M's Z-squared input, the second adds full one-SE bars, and the third shows its supported BETA-squared sensitivity analysis. Every trait remains visible. Orange triangles mark method diagnostics; the tables contain their reasons.
